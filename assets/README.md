# Kojii orange-slice artwork

`kojii-icon.svg` is a clean vector recreation of the orange-slice reference supplied
in chat, not the original 645 KB traced SVG or pixel-identical image bytes.
Replace it with the original self-contained SVG to use exact artwork.

The builder renders adaptive, themed, legacy, notification, splash and in-app logos
once at build time. Game covers and functional controls retain their own icons.
